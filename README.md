# AI SMART MATH KZ

Интерактивті математикалық білім беру платформасының жергілікті демо-прототипі.

## Іске қосу

1. `index.html` файлын Chrome, Edge немесе Firefox браузерінде ашыңыз.
2. Жоғарғы оң жақтан рөлді ауыстырып, оқушы, мұғалім және әкімші көріністерін қараңыз.
3. `ҚАЗ / РУС / ENG` мәзірі интерфейс тілін ауыстырады.

Сервер, орнатылатын пакет немесе API кілті қажет емес. Google Fonts интернет болғанда жүктеледі; интернетсіз жүйелік қаріп қолданылады.

## Прототипте жұмыс істейтін мүмкіндіктер

- Оқушының шолу беті, метрикалар, апта диаграммасы және жеке тапсырма картасы.
- Тақырып таңдау, диагностикалық сұрақтарды орындау, нәтижені есептеу және ұсыныс көрсету.
- Білім картасындағы тақырып деңгейлері мен бөлімге өту.
- Үш күрделілік деңгейіндегі интерактивті жаттығулар, жауапты тексеру және түсіндірме.
- Math Error Detective: бөлшектерге арналған демонстрациялық қате түсіндірмесі.
- Демо AI тәлімгері: бірнеше үлгі сұраққа қадамдық, алдын ала дайындалған жауап.
- Мұғалімнің сынып кестесі мен көрсеткіштері, сабақ материалының демо генераторы.
- Әкімші панелінің демонстрациялық көрсеткіштері мен басқару әрекеттері.
- Smart Diagnostics: 5–6 сынып алғышарттарын, одан кейін 7-сынып бөлшек тақырыбын ретімен бағалау; қате түрі, ереже және оқу жолы туралы қорытынды.
- Math Error Detective: есеп қадамдары мен соңғы жауапты талдау, белгілі қате үлгілеріне сай түсіндіру және түзету есебі.
- Диагностика/қате әрекеттерін `localStorage` ішінде сақтау; сол профильдегі мәліметтерді оқушы шолуы, білім картасы және мұғалім көрінісінде пайдалану.
- Есеп шешу интерфейсі: есеп шарты, шешу қадамдары және жауап енгізу; күту индикаторы; KaTeX-пен бөлшек формулаларын көрсету.
- Мұғалім кабинетінде 1–9 сынып селекторы; сыныпқа сай оқушы тізімі, есептелетін орташа көрсеткіш және тақырыптар.
- Әр сыныпқа екіден, барлығы 18 тақырыптық жаттығу; сынып және тақырып сүзгісімен есепті шешу формасына жіберу.

## Шектеулер

Бұл — браузерде жергілікті жұмыс істейтін front-end прототип. Профиль мен сынып нәтижелері демонстрациялық, оқушы енгізген диагностика мен қате талдауы осы браузердің `localStorage` қоймасында сақталады. Сервер, тіркелу, дерекқор, рөлге негізделген API рұқсаты және нақты генеративті AI қосылмаған. «AI» аталған талдау шектеулі ережелер жиынына сүйенеді. Оқу тақырыптары үлгі ретінде берілген және ресми оқу бағдарламасына сәйкестігі расталмаған.

## Құрылым

- `index.html` — HTML, CSS және JavaScript-тен тұратын бір файлдық прототип.
- `ТЗ.md` — толық техникалық тапсырма, архитектура және дерекқор моделі.

Өөрчлөлт хийхийн тулд `index.html` файлыг дурын текст засварлагчаар нээгээд хадгална уу.
